## 🚀 GitHub Pages တင်နည်း (Setup Guide)

### Method 1: Auto Deploy (GitHub Actions) — Recommended

1. Repo ကို clone လုပ်ပါ:
   ```bash
   git clone https://github.com/dev-moe-kyawaung/Dev-MKA-Portfolios.git
   cd Dev-MKA-Portfolios
   ```

2. Files တွေကို push လုပ်ပါ:
   ```bash
   git add .
   git commit -m "🚀 Initial portfolio deploy"
   git push origin main
   ```

3. GitHub → Settings → Pages → Source: **GitHub Actions** ရွေးပါ

4. Actions tab မှာ deploy ဆင်းသွားတာ ကြည့်ပါ ✅

### Method 2: Manual Branch Deploy

1. Settings → Pages → Source: **Deploy from branch**
2. Branch: `main` / Folder: `/ (root)` ရွေးပါ
3. Save နှိပ်ပြီး စောင့်ပါ (2-3 minutes)
